## 本地已检查

- 构建可重现、输入版本和文件哈希固定，启用源语句逐行对账，无静默遗漏。
- 生成正则、脚本语法、原生 jq 表达式及异常响应透传。
- 实测补丁优先级、对应 HTTPS 主机、普通账户与授权接口不被混合脚本挂载。
- 拼多多只删除投放标记项；豆瓣／知乎／小红书的大整数原文保留。
- 京东编码开屏响应、广电业务导航、优酷播放与水印、视频专用广告字段、YouTube JSON／protobuf 原始字段保留。
- 公开文件扫描：不含用户证书、控制密钥、私人地址、文件路径或设备应用库存；第三方独立脚本使用固定来源引用。

本地样例通过不是全部客户端实测通过。爱奇艺、芒果 TV、YouTube 等若没有实际设备观察，不能把样例结果写成广告已消失。

## 手机观察

设备已同步私人候选文件，保留自己的证书、家庭路由和 DNS，旧八条覆写作为停用备份。公开版不含这些私人字段；广告脚本预载内容与公开固定版本哈希核对一致。

本轮累计对13款App做25轮冷启动限时观察，另有1轮优酷短时播放观察；QQ音乐按使用者此前要求不继续复测，沿用历史。实际观察见[App 效果表](APP-STATUS.md)，机器可读摘要见 [device-verification.json](../rules/device-verification.json)。已观察到 Stash 配置诊断无警告，基于规则的 Apple 请求成功。一项原 DNS 诊断失败在升级前已出现，私人 DNS 没有改动；不能把它算成新广告规则成功或失败。

首轮豆瓣出现广告占位，已补回旧版的 API QUIC 回退后，后续连续两轮采样未见原占位并进入首页。微博首轮出现完整商业开屏，后续两轮采样未再见开屏但现金推广仍在，记录为表现波动。未完成的旧版对照不能作为“已经证明是缓存”的结论，后续若复测也应注明版本、登录态与是否清缓存。

本轮没有重装 App、执行新的缓存删除、登录、支付或修改账户权益。十秒内无有效结果、协议／认证／权限阻挡及界面干扰均不算去广告通过。原始图片、请求、设备与操作记录只留本机，不发布。

## 补测记录

同一规则下补测8款App、9轮冷启动，均安排约9.5秒退出，待上一App退出后才启动下一款。每轮采样约在第2、5、8秒；十秒内无结果就停止，不延长窗口等待。小红书补测发现页正常刷新，未见独立开屏；微博本次未见开屏但现金悬浮入口仍在；酷安再次出现黑色广告占位与倒计时。网易云音乐首页可加载，会员促销与徽章运营弹窗仍在。京东与拼多多仍有自营促销和剪贴板提示，未授权读取剪贴板。

优酷首页约5至8秒仍显示带广告标记和摇一摇跳转的商业横幅。另点入剧集后约5秒出现正片，后续画面持续变化，本次短窗口未见前贴片；但离开后画中画又出现商品推广片段，不能写成播放全程无广告。画中画遮挡的一轮京东保留为有限观察，结束播放后已另做一轮冷启动。仅保留播放可用的短时证据，不代表全部剧集、时段和广告位置通过。

YouTube补测约8秒加载出首页，首卡明确显示赞助商广告，因此从未加载完成更新为首页广告仍在。当前YouTube定向实现范围见[覆盖说明](COVERAGE.md)，播放器和Shorts仍未实机验收。

本次只更新观察记录，没有新的请求命中证据，未凭广告画面猜测域名并扩大屏蔽。规则版本和文件哈希保持不变，手机仍为1条启用、8条旧覆写停用。

## 结果怎么使用

本项目提供去广告规则及可复核的适配记录，不提供全部 App／全部广告位永久无广告承诺。换设备、账号、地区、版本及客户端缓存都可能改变表现。旧版成功、使用者反馈、本轮画面观察、请求命中和离线样例是不同证据，不能相互替代。
