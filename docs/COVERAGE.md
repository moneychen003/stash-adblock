## QX 到 Stash 的对应关系

| QX 内容 | Stash 实现 |
| --- | --- |
| 域名／IP拒绝 | 分流规则；非广告和用途不明确的广泛阻断排除 |
| URL 拒绝／跳转 | `http.url-rewrite` |
| `response-body` 文本替换 | 原创通用响应脚本，完整保留替换文本和捕获组语义 |
| `jsonjq-response-body` | 原生 `response-jq`，异常响应形状透传 |
| 请求／响应脚本 | 对应 Stash 类型；有二进制需求的使用 `binary-mode` |
| 混合功能脚本 | 仅挂广告路径，或用本仓库广告专用实现 |
| 条件语法／静态响应 | 支持条件脚本／Mock；被排除时仍有明确记录 |

小红书保留明确广告节点、开屏和搜索广告处理，保留普通图文、视频、作者身份、水印及版本信息；爱奇艺／芒果 TV 保留广告组件，保留正常内容和导航；优酷保留播放字段、付费状态、水印与青少年配置。

YouTube 仅恢复播放器、`get_watch` 内嵌播放器及带明确广告标记的 Shorts 处理，包含 JSON 与 protobuf 样例验证。普通信息流、布局、字幕和后台播放等未作全功能接入，也尚不能据离线测试保证实机播放广告均消失。

Spotify 固定上游脚本的去广告标志位于伪装 Premium／修改播放授权的同一账号属性流程，未找到可独立验证的纯广告分支，因此这组绑定排除。不能以“完整去广告”为由附带会员解锁。

## 保留的实测修复

保留豆瓣广告开关和横幅、微博推荐直播及开屏相关处理、哔哩哔哩开屏、中国广电开屏与营销位、拼多多投放标记过滤、京东开屏、酷安启动处理、QQ 音乐精确广告路径、优酷广告专用处理、雪球精确广告接口，以及知乎广告与必要传输兼容。补丁先于同用途上游脚本；与其冲突的直接拒绝由补丁接管。

豆瓣旧配置中的 `api.douban.com` QUIC 回退也已补回，并加入回归检查。保留补丁不等于当前客户端仍然通过，实际结果见[效果表](APP-STATUS.md)。

## 公开版与手机私用版

公开文件只含广告规则、脚本引用和固定来源。手机使用相同的广告规则与脚本，额外保留自己的 CA、家庭路由与私人 DNS；还可预载已核对哈希的相同脚本，降低首次下载失败的影响。这些私人字段、预载文件和原始设备记录均不发布。

许可证与固定依赖见[来源说明](../THIRD_PARTY.md)。实际启用时仍需自己的证书及可访问的脚本源；出现证书或功能异常请关闭覆写对照，不要关闭 App 自身安全校验来强行去广告。
