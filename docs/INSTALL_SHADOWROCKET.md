# Shadowrocket 安装合并模块

**当前为本地发布候选，新增脚本尚未公开；以下在线地址在正式发布后使用。**

1. 保留原节点配置，在「配置 → 模块 → ＋」添加本模块地址：

   ```text
   https://raw.githubusercontent.com/moneychen003/stash-adblock/main/rules/stash-adblock.shadowrocket.module
   ```

2. 下载并确认模块名称包含“上游与实测修复合并去广告”和 Shadowrocket。关闭上游原版广告合集、旧的定制广告模块等重复项，再启用本合并版。它不需要 Script Hub 在运行时转换规则。
3. 在当前配置中开启「HTTPS 解密」，由自己的 Shadowrocket 生成并安装自己的 CA。在 iOS「设置 → 通用 → 关于本机 → 证书信任设置」确认这张证书完全受信任。不要使用别人的证书或分享私钥。「通过 HTTP/2 进行 MitM」是可选设置，不是必须开启的另一项广告功能。
4. 使用小火箭连接后再测试；切换 Stash 与小火箭时明确当前使用哪个客户端，避免把另一端的结果算到本端。
5. 完全退出目标 App 再打开，观察第 2、5、8 秒；10 秒没有有效结果就记录并跳过。需要登录或认证时，未进入页面不能算没有广告。

如果还有旧广告，先核对模块、连接、证书及更新状态，再看[缓存与重装](CACHE-AND-REINSTALL.md)。别先删除有下载或未同步内容的 App。故障反馈请写清使用 Shadowrocket、App 版本、广告位置与是否清过缓存，并遮盖截图个人信息。

这份文件是模块，不是节点订阅，也不是完整替换配置。历史效果与限制见[实测分类表](APP-STATUS.md)。
